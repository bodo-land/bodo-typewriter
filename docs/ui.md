Design a modern, responsive web UI inspired by the clean and minimal aesthetic of GitHub.

Requirements:

* Use **Tailwind CSS** for all styling.
* Follow a **developer-focused dark theme** similar to GitHub (dark background, subtle borders, soft contrast).
* Typography should be clean and readable (system fonts or Inter).
* Layout should feel structured and spacious, with consistent padding and alignment.

UI Components to include:

* Top navigation bar with:

  * Logo (left)
  * Search bar (center)
  * Profile avatar and menu (right)
* Sidebar (collapsible) with navigation items (Dashboard, Repositories, Issues, Pull Requests, Settings)
* Main content area displaying:

  * Repository list (cards or table style)
  * Each repo should show name, description, language, stars, and last updated time
* Buttons:

  * Primary (solid)
  * Secondary (outline)
* Use subtle hover effects and transitions

Design Style:

* Rounded corners (lg)
* Soft shadows (not heavy)
* Muted color palette with accent (blue/indigo)
* Clean borders (border-gray-700 for dark mode)
* Smooth hover and focus states

Extras:

* Make it fully responsive (mobile + desktop)
* Include dark mode as default
* Use Tailwind utility classes only (no custom CSS unless necessary)
* Maintain accessibility (proper contrast, focus states)

Output:

* Provide complete HTML with Tailwind classes (or React + Tailwind if applicable)
* Keep code clean, modular, and readable
* Remove the current css
