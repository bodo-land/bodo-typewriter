# Chapter 12 — Typing Quick-Reference

This is the end-user cheat-sheet.  Print or bookmark this page.

> **Important:** Keep Caps Lock OFF.  The engine is case-sensitive.
> Press **F9** to toggle the IME on/off.

## The ng Rule

`ng` is special — it depends on what comes next:

| You type | You get | Example |
|----------|---------|---------|
| `ng` at end | anusvara ं | `sang` → सां |
| `ng` + consonant | anusvara ं | `ngk` → ंख |
| `ng` + vowel | anusvara ं + ग + vowel | `nga` → ंगा |
| `gonga` | गंगा | Full word example |

## Conjuncts (Two Consonants Together)

When you type two consonants with no vowel between them, a halant
(the joining mark ्) is inserted automatically:

| You type | You get |
|----------|---------|
| `kt` | ख्थ |
| `nd` | न्द |
| `str` + `a` | स्थ्रा |
| `kh` + `n` + `a` | ख्ना |

To **prevent** a conjunct, type a space between the consonants.

## Keyboard Layout Summary (visual)

```
Row 1:  q   w→ओ  e→ए  r→र  t→थ  y→य  u→उ  i→इ  o→अ  p→फ
Row 2:  a→आ  s→स  d→द  f→फ  g→ग  h→ह  j→ज  k→ख  l→ल
Row 3:  z   x→ष  c→च  v→व  b→ब  n→न  m→म

Shift:
Row 1:  W   E   R   T   Y→य  U→ऊ  I→य  O→व  P
Row 2:  A→आ  S→श  D→ड  F   G   H   J→झ  K   L
Row 3:  Z   X→ष  C→छ  V   B→भ  N→ण  M→ं

Two-key caps:
  NG → ङ       NY → ञ       Th → ठ       Dh → ढ
  kh → ख       gh → घ       jh → झ       bh → भ
  dh → ध       sh → श       ph → फ       th → थ
```

## Tips

1. **`kh` and `k` both give ख** — either spelling works.
2. **`t` gives थ, not त** — Bodo's default dental stop is aspirated.
3. **Capital `I` = य**, lowercase `i` = इ — don't confuse them.
4. **Capital `O` = व**, lowercase `o` = अ (inherent vowel).
5. **`w` = ओ/ो**, it is NOT the semivowel — use `O` for व.
6. **Type `oM` for अं**, not `ong` (to avoid ambiguity in long words).
7. **F9** toggles the IME — press it to switch back to English typing.
